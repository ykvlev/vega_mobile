# Stage 2 — независимая проверка визуального preview

## Объём и результат

**PASS только для перечисленных browser-сценариев независимого дизайн-прототипа
`/design-preview`.** Это не полный PASS этапа 2, не native QA и не допуск коммерции.
Исходники приложения reviewer не изменял; проверка проведена после исправлений
на готовой production web-сборке. Проверялся рабочий checkout, не удалённый CI run.

Независимая команда из корня с активированным pnpm 10.34.8:

```sh
PATH=/workspace/.tools/node_modules/.bin:$PATH \
PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH=/usr/bin/chromium \
DESIGN_PREVIEW_OUTPUT_DIR=/workspace/reference-research/stage2/independent \
pnpm test:design
```

Результат: **7 passed, 0 failed, 0 skipped**, exit 0, 5.3 s. Runner самостоятельно
запустил локальный Next server на 3100; внешний base URL не подставлялся.
Chromium — системный `/usr/bin/chromium`, а не доказательство прохождения всех
браузеров. Снимки и результаты этого запуска находятся в указанной папке вне Git.

## Выполненные сценарии

1. Поиск, пустой результат, категории и детали демонстрационных товаров;
   Graphite 17 м и Clear 15 м, правильная длина Clear в локальном подборе.
2. Метры и рулоны одного товара сохраняются разными строками; удаление каждой,
   пустое состояние, очистка после reload, отсутствие commerce write requests
   и кнопок оформления/оплаты.
3. Гостю не показаны цены/численные остатки в проверенном UI, отсутствует API
   traffic в данном пути. Source review fixtures не выявил коммерческих полей.
4. Диалог входа получает keyboard focus и возвращает его на кнопку; диалог
   прямо сообщает, что вход не подключён и credentials не запрашиваются.
5. Нет горизонтального переполнения при ширине 320 px в основном пути.
6. Реальный render главной и каталога при ширине 390 px со снимками.
7. Реальный render главной и каталога при ширине 1440 px со снимками.

Мобильный снимок главной из независимого запуска дополнительно просмотрен.
Скриншоты подтверждают render, а не pixel-perfect соответствие pushr.

## Закрытые замечания

**Потеря keyboard focus после удаления — исправлено и независимо перепроверено.**
Ранее удалённый focused control оставлял `document.activeElement` на BODY.
Теперь ref map и layout effect переводят фокус на следующую/предыдущую кнопку
удаления; после последней позиции — на CTA пустого состояния. Browser-тест
подтвердил удаление первой и последней строк клавишей Enter, обе цели фокуса
и live announcement удаления. Ветка previous control просмотрена в коде,
но отдельно как третий браузерный сценарий не запускалась.

**Общая длина 17 м в деталях/подборе — исправлено и перепроверено.**
UI берёт длину из выбранного fixture. Clear имеет 15 м; первый тест проверил
и карточку, и строку рулона в подборе. Это демонстрационные характеристики,
не подтверждение импорта реального каталога.

## Границы допуска

- Только fixtures и React state, без API, авторизации, реальных остатков,
  заказов, резервов или платежей. Reload очищает локальный подбор.
- Цветовая студия — явно обозначенная 2D-иллюстрация, не готовый 3D.
- Проверены Chromium и указанные размеры; iOS/Android native, screen reader,
  крупный системный текст, все контрастные пары и остальные браузеры не проверены.
- Отсутствие API traffic в тестовом пути не является аудитом всей будущей системы.
- Отдельный CI job design-preview не содержит deploy и не снимает quality gate.
  Фактические required checks/branch protection этим review не подтверждены.
- Stage 1 по-прежнему заблокирован открытым high advisory node-forge; успешный
  независимый preview не отменяет security/QA-ограничений и не разрешает релиз.

Новых конкретных дефектов в проверенном исправленном объёме не обнаружено.
Непройденные будущие проверки не переименованы в PASS.
