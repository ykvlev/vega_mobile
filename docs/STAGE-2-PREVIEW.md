# Независимый preview второго этапа

Статус: визуальный web-прототип, разрешённый пользователем параллельно
заблокированному этапу 1. Не является полным допуском этапа 2, native UI или продаж.
Исходная ветка: feat/stage-2-design-preview, base — feat/stage-1-bootstrap.

## Сделано

- Семантические design tokens для web/native адаптеров.
- Отдельная route /design-preview, не заменяющая homepage админки.
- Главная с оригинальным сгенерированным hero, категории, поиск и фильтры.
- Карточки, размеры у каждого демо-SKU, разные 15/17 м в fixtures.
- Локальный подбор с раздельными строками метры/рулоны, без резервов/цен.
- Профиль, native dialog с фокусом, статичная 2D цветовая иллюстрация.
- Навигация, reduced motion, адаптация 320/390/1440 и keyboard flows.
- Playwright tests и отдельный CI job, не ослабляющий quality/audit.

Fixtures не содержат цен/остатков, нет авторизованного режима или регистрации.
3D вкладка прямо сообщает о 2D концепции; native renderer не реализован.

## Найдено и исправлено

1. dotenv загружал NODE_ENVdevelopment из API.env в Next production build.
   Root команды теперь явно задают build/dev режимы. Повторная сборка с локальным
   .env прошла. Environment-only fix выделен в общий commit и fast-forward
   перенесён в ветку этапа 1, без изменения его зависимостей и истории.
2. Размеры detail/cart были частью текста; теперь берутся из выбранного SKU.
   Браузер различает Clear15м и Graphite17м, включая строку подбора.
3. Удаление клавиатурой оставляло фокус в BODY. После DOM commit фокус переходит
   на следующий/предыдущий control либо CTA пустого состояния; live region
   объявляет удаление. Проверены первое и последнее удаление.

## Проверки

Production build админки, TypeScript, ESLint и Prettier выполнены.
Семь браузерных тестов прошли без пропусков и повторов. Независимый critic-review
и retest — STAGE-2-QA.md. Первый QA-agent запуск оставил passed артефакт,
но его финальный turn завершился usage limit — это не выдаётся за отчёт.
Полный security audit всё ещё FAIL из-за одного node-forge HIGH; новых findings нет.

Артефакты: /workspace/reference-research/stage2/playwright и
/workspace/reference-research/stage2/independent. CI проверяется отдельно:
локальный успех не приписывается GitHub. Публичного хостинга preview нет.

сохранение корзины, рабочая 3D-модель и проверка на iPhone/Android отсутствуют.
