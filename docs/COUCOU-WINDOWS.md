# Coucou на Windows для локальной работы над VEGA

Статус: инструкция по проверенной документации Coucou, не выполненная установка.
У облачного агента нет доступа к пользовательскому Windows-компьютеру.
Текущая облачная сессия Codex не подключена к локальному Coucou.

## Установка

1. Открыть https://github.com/Louis-CFM/coucou/releases/tag/windows-latest
   и установить официальный Windows installer подходящей архитектуры.
   Если опубликованы checksums, проверить скачанный файл. При блокировке
   защитой Windows не отключать защиту автоматически; проверить подпись/источник.
2. Запустить Coucou.
3. Settings → Agents → Codex → Install hooks. Просмотреть diff и путь резервной
   копии, подтвердить изменение локально. Установщик сливает настройки,
   а не должен заменять неизвестную конфигурацию целиком.
4. Документация Coucou указывает пользовательский файл
   %USERPROFILE%\.codex\hooks.json и команду /hooks внутри Codex для доверия.
   Это пользовательская интеграция, не только один репозиторий. Не переносить
   Windows-пути hook executable в Git или в облачный Linux.
5. Запустить установленный локальный Codex CLI из каталога локального VEGA.
   Если /hooks отсутствует, зафиксировать версию codex --version и проверить
   совместимость; не придумывать схему hooks.json.

## Проверка

В локальной сессии VEGA отправить безопасную задачу чтения файлов. В Coucou
должна появиться сессия Codex. Для проверки Allow/Deny нужен настоящий запрос
разрешения, который требует политика Codex: не ослаблять политику ради теста.
Проверить отказ и поведение при закрытом Coucou. Не объявлять интеграцию
работающей лишь по наличию hooks.json.

Исходная инструкция:
https://github.com/Louis-CFM/coucou/blob/main/windows/README.md#supported-agents

## Состояние файлов VEGA

Документы проекта сейчас находятся в облачной /workspace/vega_mobile/docs.
Они пока не отправлены в GitHub. Клонирование пустого удалённого репозитория
на Windows не перенесёт эти файлы. Для продолжения локально нужен отдельный
перенос или публикация текущих изменений; не утверждать, что синхронизация уже есть.

## Удаление интеграции

Использовать удаление hooks в Coucou Settings → Agents → Codex и просмотреть
diff. Не удалять весь пользовательский hooks.json: там могут быть чужие hooks.
