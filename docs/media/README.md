# VEGA: демонстрация интерфейса

`vega-ui-preview.mp4` — запись работающего веб-прототипа `/design-preview`
в мобильном размере 390 × 844. Это текущая временная тема без брендбука.

Сценарий: главная, каталог, поиск Graphite, карточка с длиной рулона 17 м,
подбор 5 метров, прозрачная плёнка с рулоном 15 м, локальный подбор.

Запись демонстрирует интерфейс и локальные взаимодействия на тестовых товарах.
Она не демонстрирует готовую авторизацию, интеграцию 1С, оплату, реальные
остатки или native-приложение. Раздел 3D в эту запись не включён.

MP4: H.264/yuv420p, без звука, faststart для просмотра с телефона.
