В публичном API каждого кандидата проверены: `isDownloadable=true`, лицензия
CC-BY 4.0 и текст «Author must be credited. Commercial use is allowed.».
Источник проверки: `https://api.sketchfab.com/v3/models/{uid}`, где uid —
последние 32 символа ссылки на модель. В описании Urban ’10 автор также прямо
разрешает модификацию и включение в цифровой продукт.

Лицензия карточки не заменяет осмотр архива: нужно проверить встроенные марки,
состав файлов, UV, разбиение кузова/стекла/колёс, нормали, материалы и фактические
размеры. Количество faces из API не выдаём за проверенное количество triangles
выгруженного GLB. Публичный прямой URL архива без авторизации не подтверждён.

## Следующий шаг

Получить исходники штатным способом под аккаунтом владельца, сохранить лицензию
и атрибуцию, проверить пригодность двух основных кандидатов и прогнать через
наш pipeline. Сначала — седан MMC и подробный SUV MMC; low-poly варианты
рассматривать отдельно, если их качество подходит согласованному стилю.

Текущий концепт-кар остаётся проверкой движка. Он не считается готовым набором
массовых автомобилей. Изображения/материалы плёнок и связь с SKU также ещё
не утверждены. [Текущий 3D-стенд и подэтапы](3D-CONFIGURATOR.md).
