# Этап 7. 3D-конфигуратор

Статус: **в работе; первый технический срез реализован**. Текущий приоритет проекта.

## Готово

Настоящая сцена Three.js/WebGL2 с GLB: вращение, приближение, четыре ракурса,
шесть демонстрационных цветов и три финиша кузова. Отдельно сохранены стёкла,
колёса и салон; собственный номер VEGA. Есть восстановление после ошибки,
статичный fallback, освобождение ресурсов и рендер по требованию.

Модель с проверенной лицензией оптимизирована с 11,78 до 5,45 МБ,
с 213 347 до 103 689 треугольников, со 108 до 23 примитивов. Pipeline воспроизводим,
ассет проверяется офлайн, атрибуция сохранена. Реальные скриншоты получены
из WebGL canvas, а не нарисованы для демонстрации.

Добавлен мобильный вход с главной: отдельный экран WebView/iframe, постоянные
выход и каталог, строгий односторонний lifecycle bridge, fallback и таймаут30сек.
Токены/пароли в сцену не передаются. Для подключения нужен отдельный HTTPS-хост;
публичное развёртывание пока не выполнено. Выбор не переносится в SKU.

## Что проверено

Локально: 64 unit/tooling, WebGL7/7, mobile-studio3/3 и прежние mobile API E2E3/3;
сборки web/Next, генерация native-проектов и Hermes JS exports iOS/Android;
типы/линтер/форматирование/frozen install и история секретов. Проверка
configurator-3d сохранена, добавлена отдельная mobile-studio. Результаты удалённого
CI смотреть в PR №15; удачный browser-прогон не подменяет физическую приёмку.
Это не проверка скорости, нагрева или памяти физических телефонов.

## Что осталось

1. Получить и проверить модели массового седана и кроссовера — выбор пользователя.
2. Настроить материалы по реальным образцам плёнки и утвердить внешний вид.
3. Развернуть отдельный HTTPS-хост, сохранить выбор между открытиями и связать известные ID с товарами.
4. Возобновить проверку iPhone/Android, память/нагрев/background и общую приёмку.

Приёмка на физических телефонах отложена пользователем. Концепт-кар — проверка
движка, а не утверждённый набор массовых автомобилей. Палитра не подменяет
реальные SKU, цены или остатки. Отсутствие 1С не мешает независимой работе над 3D.
