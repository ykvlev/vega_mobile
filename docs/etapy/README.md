## Цикл каждого этапа

Задача и критерии → ветка → реализация → локальная проверка → push/PR → CI → проверка качества и безопасности → исправление дефектов → итог. Слияние, staging и production допускаются после соответствующих проверок; документы не требуют фиктивного деплоя.

Последний проверенный мобильный коммит: `c877c91`. В [CI 40835039145](https://github.com/ykvlev/vega_mobile/actions/runs/40835039145) прошли все шесть отдельных проверок интерфейсов, включая мобильную с JS-компиляцией iOS/Android и 3 E2E. Общие тесты и сборки прошли; quality остановлен только на известном аудите node-forge. На физических телефонах приложение ещё не проверено.

Старый desktop-редактор — архивный стенд. Отдельной админки в целевом продукте нет: менеджеры работают в 1С. Историческое видео относится к первому дизайну и не демонстрирует текущий мобильный клиент.
