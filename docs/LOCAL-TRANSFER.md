# Перенос в Windows: Documents/vega

Архив — снимок файлов из облачной сессии. Он не содержит запущенных процессов,
аккаунтов, секретов, Git metadata или полную историю чата. Скриншоты из сообщений
не доступны как отдельные файлы: их наблюдаемые особенности записаны в дизайн-брифе.
Официальные промоскриншоты pushr включены в references/pushr.

## Продолжение

1. Распаковать содержимое архива прямо в уже созданную папку vega, чтобы внутри
   неё были docs, inputs, references и START-HERE.md, без лишнего уровня vega/vega.
   Если есть совпадающие пользовательские файлы, не перезаписывать без сравнения.
2. В Codex открыть именно эту локальную папку, создать локальную задачу.
3. Попросить прочитать START-HERE.md, docs/HANDOFF.md, docs/DECISIONS.md,
   docs/ROADMAP.md и docs/TEAM.md и продолжить этап 0.
4. Проверить фактическую ОС/рабочую папку перед установками и командами.
5. Coucou: docs/COUCOU-WINDOWS.md. Установка на Windows и hooks пока не выполнены.

## Git

Проект связан с https://github.com/ykvlev/vega_mobile.git. На момент подготовки
экспорта локальный Git был без коммитов, документы не отправлялись в GitHub.
Git metadata не переносится, чтобы не копировать облачную конфигурацию.
Локальный агент должен сначала проверить существующий .git/remote и актуальное
состояние origin, затем настроить Git без reset/force push. Этот перенос сам по
себе не публикует ничего. inputs и references проверить перед добавлением в Git:
переписка может содержать личные сведения; сторонние материалы — ограничения прав.

теперь принят документарно. В первом экспорте оставалось свести спецификации:
телефон+пароль сначала; готовые отрезы продаются при <=2 целых рулонах;
менеджер согласует заказ до 100% предоплаты; 1С обязательна до реальных продаж.
Нужно закрыть cart lineId и recovery по idempotency key; API-CONTRACT.md
планировался, его наличие/содержимое проверить. Отсутствие файла не заменять
заявлением о завершении контракта. Эти сведения описывают старый экспорт: новый независимый review выполнен
и сохранён в STAGE-0-QA.md/CRITICAL-REVIEW.md текущей папки.
