# VEGA: интерактивный 3D-конфигуратор

По решению пользователя от 29 октября 2026 этап 7 стал текущим приоритетом.
Приёмка приложения на физических телефонах отложена, а не завершена.

## Что реализовано

Рабочая браузерная сцена `/configurator3d` на Three.js/WebGL2. Это настоящая
геометрия GLB с камерой и освещением. В существующей цветовой студии добавлена
ссылка на сцену; старый 2D-эскиз явно обозначен статичным.

- Вращение мышью/касанием, приближение, четыре ракурса, сброс и клавиатура.
- Шесть демонстрационных цветов; глянец, сатин и матовый финиш.
- Цвет/финиш применяются только к материалам Paint 1 Carmine / Paint 2 Carmine.
  Стёкла, колёса, салон и оптика не меняются при выборе плёнки.
- Отдельная студийная настройка стекла/металла/света и собственный номер VEGA.
  Контактная тень приближённая, без дорогого дополнительного прохода всей модели.
- Ограничение pixel ratio, рендер по требованию в статичном состоянии, пауза
  фоновой вкладки; автовращение включается пользователем.
- Ошибка загрузки, отсутствие WebGL и потеря контекста дают фото и повтор.
  Каталог доступен независимо от 3D. Сцену можно скрыть и загрузить снова.
- При завершении отменяются загрузка/RAF/наблюдатели/обработчики, освобождаются
  geometry, material, texture, ImageBitmap, environment и WebGL renderer.
  Поздно декодированная сцена после ухода тоже освобождается.

Цвета не связаны с реальными SKU и наличием. Числа PBR-параметров — инженерная
визуализация, не измеренные характеристики плёнок. Реальные образцы, калибровка
света, фото и подтверждённые данные потребуются перед выбором товара покупателем.
Есть отдельный экран мобильного приложения с WebView-транспортом и browser-проверкой встроенной сцены. Проверка на физических iPhone/Android отложена; native-конфигуратор ещё не принят.

Car Concept — оптимизированная модель концепт-кара, не утверждённая модель
автомобиля заказчика. Источник закреплён commit/SHA-256 в manifest.json.
Модель/текстуры © 2024 Darmstadt Graphics Group GmbH, Eric Chadwick, CC BY 4.0.
Атрибуция показана в интерфейсе и сохранена вместе с лицензией.

Исходные логотипы Khronos/3D Commerce исключены из CC-лицензии. Из адаптированного
ассета удалены три содержащие логотипы текстуры и steering emblem; исходное
уведомление о марках сохранено для происхождения. VEGA не заявляет сертификацию
или поддержку со стороны авторов/организаций.

Файлы и точные показатели: `apps/admin/public/3d/car-concept/manifest.json`,
ATTRIBUTION.md, SOURCE-LICENSE.md, SOURCE-TRADEMARK-NOTICE.txt и CC-BY-4.0.txt.

## Измеренные характеристики ассета

| Показатель | Исходник | Текущий ассет |
|---|---|---|
| Размер GLB | 11 778 688 байт | 5 447 004 байт |
| Треугольники | 213 347 | 103 689 |
| Примитивы после упрощения, до/после объединения | 108 | 23 |
| Текстуры | 14 | 10, не более 1024 px |

Оценка декодированных RGBA-текстур: 7,45 MiB без mipmaps, около 9,93 MiB с ними.
Это расчёт по размерам изображений, не полная измеренная память GPU: среда,
рендер-буферы, геометрия и собственные текстуры номера/тени добавляются отдельно.
Части объединены статично; шарниры открывания дверей не входят в текущий срез.
Положение над площадкой вычисляется по точным вершинам после transforms,
а не по раздутым локальным AABB объединённых колёс.

Следующий набор по ответу пользователя: **массовые седаны и кроссоверы**.
Конкретные автомобили, исходники и права ещё предстоит выбрать; текущий
концепт-кар служит проверке движка, а не подменяет этот согласованный приоритет.

## Ограничения загрузки и безопасность

Сцена принимает только известные ID цветов/финишей/ракурсов и один локальный
URL модели с версией SHA-256 из manifest, чтобы обновления не застревали в кеше.
Пользователь не задаёт URL, shaders или исполняемый код. Модель
загружается без cookies/bearer, redirects запрещены, объём ограничен 8 MiB.
Встроенные внешние URI images/buffers отвергаются до GLTFLoader. CDN и сторонние
текстуры/декодеры во время работы не нужны. Автономность загрузки модели не
означает офлайн-доступность всей Next-страницы после закрытия браузера.

Мобильный экран использует `/configurator3d/embed` на отдельном origin. Внутри
нет переходов на каталог, аккаунт или внешние сайты; атрибуция сохранена текстом.
Кнопки выхода и каталога принадлежат React Native и доступны при сбое сцены.
Страница ограничена CSP: только свои ресурсы, без форм и вложенных frames.

Мост односторонний, с двумя строгими сообщениями v1, до 256 символов:

- `{version: 1, type: "vega-studio", phase}` — loading/ready/failed/paused.
- `{version: 1, type: "vega-studio-choice", choice: {color, finish}}` — только
  шесть известных ID цвета и три ID поверхности; сообщение отправляется при
  выборе пользователем или явном сбросе. Startup не перезаписывает сохранённый выбор.

Лишние поля, неизвестные ID/версия и повреждённый JSON отвергаются. Host проверяет
источник и origin iframe либо точный URL native-документа. Команд, токенов,
произвольных URL и исполняемого кода в протоколе нет. В browser публичный envelope
отправляется parent через postMessage с `*`; он содержит только публичную фазу/демонстрационные ID, без аккаунта или товаров;
принимающая сторона проверяет source и origin.

Native WebView14.0.1: incognito, выключены shared/third-party cookies,
DOM storage, mixed content, file access, media capture, popup и геолокация.
Все навигации проходят callback с точным allowlist URL; `originWhitelist=['*']`
намеренно предотвращает автоматическую передачу запрещённых URL в OS Linking.
Отдельный web-экспорт использует sandboxed cross-origin iframe, без referrer.
Chromium поддерживает credentialless; его наличие до первого запроса и отсутствие
cookies проверяются в browser suite. В других движках credentialless может не
поддерживаться: требуется отдельный origin без авторизации и общих Domain cookies;
полная изоляция cookies на Safari/native ещё не подтверждена устройствами.

Загрузка начинается только после открытия студии. Ошибка или 30 секунд без ready
размонтируют транспорт; повтор создаёт новый экземпляр. Закрытие и переход в
каталог тоже удаляют транспорт. Выбор сохраняется в AsyncStorage приложения под ключом
`vega.public-studio-choice.v1`: version + color/finish, без токена/клиента/SKU/цены.
Восстанавливается после закрытия студии и повторного запуска приложения. Ошибка
чтения/записи даёт сообщение; выбор в памяти остаётся доступен. Повтор сохранения
записывает текущий видимый выбор. Повреждённое значение не приводит к удалению
других данных. Операции сериализованы; позднее чтение не затирает новый выбор.

Начальный выбор передаётся в фиксированный `/configurator3d/embed` двумя query
полями color/finish, только после проверки общей схемой. Неизвестные/повторные
поля и ID дают стандартный графит/глянец. Это публичные предпочтения, не секреты;
произвольных URL, материалов или исполняемых команд по-прежнему нет.
Начальный URL фиксируется на время экземпляра, поэтому сохранение не перезагружает
модель и не сбрасывает камеру. После ошибки загрузки повтор получает последний
выбор. «Сбросить выбор» возвращает графит/глянец и сохраняет сброс.

Каталог получил вход в 3D; возврат из студии сохраняет текущую вкладку и текст
поиска. Демонстрационные цвета по-прежнему не связаны с артикулами, остатками,
ценами или заказом: переход в каталог не подменяет собой выбор реальной плёнки.

## Запуск и проверки

Из корня проекта после установки закреплённых зависимостей:

```sh
pnpm build:admin
pnpm dev:admin
```

Открыть `http://localhost:3000/configurator3d`.

```sh
pnpm assets:3d
pnpm check:3d
pnpm test:3d
pnpm test:mobile:3d
```

`assets:3d` — воспроизводимое преобразование из закреплённого внешнего исходника:
проверка SHA-256, удаление марок/вариантов, упрощение, WebP и manifest. Требует
npm-зависимостей и сети для исходника. `check:3d` проверяет уже сохранённый ассет
офлайн: hash/размеры/структуру/политику ресурсов и бюджеты. Обычный CI не скачивает
модель заново, использует проверенный файл из Git.

`test:3d` запускает production Next на 3108 и Chromium с настоящим WebGL через
SwiftShader. Проверяет материалы/геометрию, управление, отсутствие credentials,
покой рендера, освобождение GPU-буферов, восстановление контекста, сбой сети,
отсутствие WebGL и запрет внешних URI. Это не измерение FPS, нагрева или памяти
физического телефона. Скриншоты получаются из реального canvas, не imagegen.

## Мобильный запуск

`EXPO_PUBLIC_STUDIO_URL` — необязательный origin отдельного 3D-хоста, без пути,
query, fragment и credentials. Для native production разрешён HTTPS. Для локальной
browser-проверки разрешён HTTP loopback. Origin приложения/API запрещён. Значение
встраивается при Expo export; изменение переменной после сборки не меняет bundle.
Пустое значение показывает доступный экран ошибки и сохраняет рабочий каталог.
Публичный HTTPS-хост ещё не развёрнут; native-сборка на телефоне не выполнялась.

Локальный интеграционный запуск:

```sh
EXPO_PUBLIC_API_URL=http://127.0.0.1:3106 EXPO_PUBLIC_STUDIO_URL=http://127.0.0.1:3108 pnpm build:mobile
pnpm build:admin
pnpm test:mobile:3d
```

Suite сама поднимает production Next на 3108 и mobile export на 3106; 1С, API и
база для неё не нужны. В отдельном CI job выполняются те же сборки/проверки.

### Проверки сохранённого выбора

Общие схемы проверяются модульными тестами; hook проверяется на race чтения/записи,
повторный mount/StrictMode, повреждённые данные, отказ хранилища и повтор.
Browser-suite `test:mobile:3d` дополнена полным перезапуском web export, переходом
каталог → студия → каталог с сохранением поиска, сбросом и реальным отказом
localStorage.setItem. Проверяется, что выбор не вызывает повторную навигацию iframe.
Native JS exports проверяют компиляцию; фактическая долговечность native AsyncStorage
и ресурсы WebView на устройствах относятся к отложенной физической приёмке.
